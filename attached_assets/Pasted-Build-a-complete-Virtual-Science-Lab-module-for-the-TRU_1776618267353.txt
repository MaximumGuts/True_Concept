Build a complete Virtual Science Lab module for the TRUE CONCEPT Learning Portal web app.

The Virtual Lab must support interactive physics and chemistry experiments for Class IX and Class X based on NCERT concepts.

The system must be mobile-friendly, interactive, and educational.

VIRTUAL LAB STRUCTURE

Create a new main section in the platform called:

Virtual Lab

Inside it organize experiments by subject.

Structure:

Virtual Lab
→ Physics Lab
→ Chemistry Lab

Each subject should contain experiment cards.

Each card opens a dedicated experiment page.

EXPERIMENT PAGE STRUCTURE

Each experiment page must contain the following sections:

Experiment Title
Objective
Theory
Apparatus
Procedure
Interactive Simulation Area
Observation Table
Result Section
Explanation Video (YouTube embed)

The design must be clean and mobile friendly.

SIMULATION ENGINE

Build a reusable simulation framework so experiments can reuse components.

The simulation system should support:

Interactive sliders
Draggable objects
Angle controls
Measurement tools
Graph plotting
Dynamic calculations

Use visual animations and interactive components so students feel they are performing a real experiment.
