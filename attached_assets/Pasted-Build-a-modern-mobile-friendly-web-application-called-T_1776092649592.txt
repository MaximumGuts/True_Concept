Build a modern mobile-friendly web application called TRUE CONCEPT Learning Portal for a tuition institute.

The purpose of the app is to provide digital study material, MCQs, explanations, and a virtual science lab for Class IX and X students (SEBA / CBSE).

The platform should work smoothly on mobile devices first and then desktop.

Use a clean, modern UI with a minimal design, suitable for students.

CORE FEATURES

The system should have two roles

Admin (Teacher)
Student

Students can only access study materials.
Admin can upload and manage content.

STRUCTURE OF THE PLATFORM

The app should have the following sections:

Home Page

Display:

TRUE CONCEPT logo/title
Short tagline: “Concepts. Clarity. Confidence.”

Sections on homepage:

• Subjects available
• Features of the platform
• Login button
• Student dashboard preview

The design should look clean, premium and modern.

SUBJECT STRUCTURE

Content should be organized in the following hierarchy:

Subject → Class → Chapter → Content

Subjects:

Mathematics
Science
Advanced Mathematics

Classes:

Class IX
Class X

Each chapter should contain:

Notes
MCQ Quiz
Question & Answer
Explanation Video

NOTES SYSTEM

Admin can upload chapter-wise notes.

Supported formats:

PDF
Text notes
Images of notes

Students should be able to:

View notes
Download notes
Open notes in mobile friendly viewer

MCQ PRACTICE SYSTEM

Each chapter should have a MCQ practice section.

Features:

Multiple choice questions
Instant answer checking
Explanation after answering
Score calculation
Attempt again option

Show results like:

Correct answers
Wrong answers
Percentage score

QUESTION ANSWER SECTION

Each chapter should have:

Important exam questions
Detailed answers
Step-by-step explanation

This should be displayed in a clean readable format.

YOUTUBE EXPLANATION VIDEOS

Admin should be able to attach a YouTube video link to each chapter.

Students should see:

Embedded YouTube player
Video title
Short description

Videos should open inside the app page.

VIRTUAL SCIENCE LAB

Create a Virtual Science Lab section for Class IX and X science experiments.

Students should be able to interact with simulations.

Examples:

Light reflection experiment
Refraction through glass slab
Electric circuit simulation
Lens experiment
Magnet experiment

Each experiment page should include:

Experiment objective
Interactive simulation area
Step-by-step procedure
Expected result
Explanation

Simulations should be interactive and visual.

Use HTML Canvas or interactive components to simulate experiments.

The interface should feel like a small digital lab.

STUDENT DASHBOARD

After login, students should see:

Subjects available
Progress tracking
Recently opened chapters
MCQ scores

Each subject card should open chapters.

ADMIN PANEL

Admin should have a dashboard to manage content.

Admin capabilities:

Add subjects
Add chapters
Upload notes
Add MCQs
Add questions and answers
Attach YouTube video links
Manage virtual lab experiments

Admin should also be able to:

Edit content
Delete content
